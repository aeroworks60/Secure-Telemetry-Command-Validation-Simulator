04 / AUTHENTICATION

Authenticate before you trust

HMAC-SHA256

Each message can carry an auth_tag computed with a shared secret key on the server. Tampered, unsigned, wrong-key and malformed-tag messages are rejected before any other rule runs, so they cannot consume a message ID or sequence number. HMAC authenticates; it does not encrypt.

Scope by design

Sentinel is a local educational simulator. Its audit trail is in memory and is neither persistent nor tamper-proof. HMAC authentication (shared key, server side) is a demonstration of message authenticity and integrity. It does not encrypt messages or make this prototype production-secure.
